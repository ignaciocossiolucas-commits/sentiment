¿Cómo funciona la actualización de este panel?

Cada jueves a las 22:00 UTC, un job de GitHub Actions ejecuta scripts/fetch_sentiment.py, que captura 5 de los 8 indicadores (VIX, CNN Fear & Greed, AAII, Put/Call de Cboe y % de S&P500 sobre su media de 200 sesiones) y los escribe en data/sentiment.json. Este panel HTML lee ese archivo al cargar — por eso no hace falta tocar nada para que estén al día.

Los otros 3 (NAAIM, Insider Buy/Sell Ratio, Smart/Dumb Money) son de fuentes de pago sin API pública, así que el script nunca los toca. Para actualizarlos: edita directamente data/sentiment.json en GitHub (botón del lápiz, sin necesidad de clonar nada), cambia el value/smart/dumb y la fecha manual_updated, y haz commit. La próxima ejecución automática respeta esos campos tal cual los dejaste.

Si data/sentiment.json no se puede leer (por ejemplo, si abres este archivo con doble clic en vez de vía GitHub Pages), el panel cae automáticamente en el último snapshot embebido en el propio HTML, para que nunca se rompa.

Lanzar la captura a mano en cualquier momento: pestaña Actions del repo → Captura semanal de sentimiento → Run workflow.

¿Cómo se calcula el Índice de Sentimiento Agregado (ISA)?

Cada uno de los 9 indicadores se normaliza primero a una escala 0-100 donde 100 siempre significa "más codicia/optimismo" (el VIX y el Put/Call se invierten, porque en ellos un valor bajo es la lectura optimista). Luego se pondera: F&G 20%, % S&P500>200d 15%, AAII 15%, VIX 10%, Put/Call 10%, NAAIM 10%, Insider Ratio 10%, Dumb Money 5%, prob. recorte Fed 5%. La media ponderada es el número que ves en el velocímetro.

Los pesos están en COMPOSITE_CONFIG, al principio del <script> de index.html — si quieres darle más o menos peso a algún indicador, es ese único array el que hay que tocar, todo lo demás (gauge, desglose, colores) se recalcula solo.

Cada tarjeta lleva su propia fecha porque estas fuentes no publican con la misma cadencia: VIX y CNN se mueven a diario, AAII es semanal, Put/Call y breadth rondan la semana, e insiders y Smart/Dumb Money se agregan por quincena o mes. No mezcles estas fechas como si fueran "hoy". No es asesoramiento de inversión.
